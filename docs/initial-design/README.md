# Original concept sheets

These four handwritten sheets record the early design discussions between Ray Liu and Weiguo Tang. They show the intended story progression; they are not evidence that every pictured scene is finished in the current playable build.

1. [Darkness and the first memory fragments](initial_design_sheet_01_core_premise_and_phase1.jpg): the first layout was side-scrolling and nearly black. A small glowing block and collected memories/lights connected movement to the story.
2. [Volcanic escape](initial_design_sheet_02_phase2_escape.jpg): collapsing ground and a pursuing hazard increase the pace. The player escapes toward a bright opening.
3. [Water, island, and color recovery](initial_design_sheet_03_phase3_water_and_island.jpg): action slows; the character reaches a leaf and island, interacts with fruit, and yellow, red, then blue return to the scene.
4. [Return and hospital ending](initial_design_sheet_04_phase4_return_and_ending.jpg): earlier phases visually reconnect, an island door leads toward a hospital awakening, and the journey closes with family and credits.

These are reading aids for hard-to-read handwritten pages, not transcriptions or proof that every early idea survived. The later build expanded the water, island, and ending into 3D. See [build provenance](../BUILD_PROVENANCE.md) for the source/build distinction.
