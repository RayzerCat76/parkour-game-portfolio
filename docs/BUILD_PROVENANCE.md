# Parkour game: review build and source provenance

The [v580 macOS review build](https://github.com/RayzerCat76/parkour-game-portfolio/releases/tag/portfolio-2026-11-01) was built with Unity 6000.4.11f1 on 26 October 2026. It is the downloadable app presented for review. Ray confirms a complete start-to-ending manual recording of v580 on 1 November; a 71.70-second silent edit is prepared locally for the Maker Portfolio and is not hosted here. A separate automated run on 1 November reached Fragments, failed to verify the fourth voice-route movement, and ended with a native double fault before later chapters. These are distinct observations.

The preserved build record reports a successful build at 19:19 Shanghai time on 26 October. A local audit compared every file in the v580 release archive with the preserved build app: all 192 app files matched byte for byte. This identifies the compiled review candidate, but the build record does not identify an exact Unity source snapshot.

The public `UnityProject/` was copied from the later development worktree after a v591 walking experiment. That experiment built but failed the street-turn review, and it was not released. No exact v580 source snapshot has been identified for this portfolio repository. **The automatic GitHub source archive for the v580 release is therefore not the source that built the v580 app.** The public project shows the latest development code and assets; the release asset is the playable review candidate. Do not describe them as a reproducible source/binary pair.

For the design-to-build trail, start with the [four original concept sheets](initial-design/README.md), then the [development account](../PORTFOLIO.md), the dated v241/v306/v316 clips and edited v580 manual gameplay prepared as SlideRoom attachments, and the v580 release. The gameplay edit is an excerpt, not an unbroken recording.
