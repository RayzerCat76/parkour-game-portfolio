# Contributions and source credits

- **Ray Liu:** project direction; implementation specifications and prompts; review of code and generated media; gameplay, movement, lighting, and visual iteration; playtesting and version decisions.
- **Weiguo Tang:** shared original design and lore discussions with Ray; feedback on the game. Weiguo gave permission for this portfolio publication. The handwritten concept sheets came from that shared design process; individual pen strokes are not separately attributed.
- **OpenAI GPT/Codex:** generated or substantially assisted with game code, artwork/textures, editor and build tooling, tests, and documentation from Ray's specifications and feedback. These are AI-assisted outputs, not claimed as wholly hand-coded or hand-drawn by Ray.
- **Apple macOS text-to-speech:** Ray generated the prerecorded story dialogue locally with installed system voices: Daniel for the doctor and some memory/volcano lines, Moira for the nurse, and Samantha for the mother and some memory lines. Hospital lines were exported as AIFF at 175 words per minute. Memory echoes were generated at 155 words per minute, filtered, given a short echo, and exported as mono 24 kHz WAV files. Unity plays the clips at story triggers. These are synthetic voices, not recordings of Weiguo or other collaborators. Use and distribution of System Voices are governed by [Apple's macOS license](https://www.apple.com/legal/sla/docs/macOSTahoe.pdf).
- **Unity Technologies:** Unity engine and packages supply rendering, physics, input, UI, and build infrastructure. The project uses Unity 6000.4.11f1.
- **MakeHuman:** CC0 source material is present in `UnityProject/Assets/ReturnRedesign/Art/Resources/ReturnRealism/`. The accompanying CC0 notice is preserved there. Ray/GPT adapted the material for this game's character/scene work.
- **Poly Haven:** [Forest Ground 01](https://polyhaven.com/a/forrest_ground_01) texture by Rob Tuytel supplies the island ground maps; [Namaqualand Boulder 06](https://polyhaven.com/a/namaqualand_boulder_06), photographed by Greg Zaal and modelled by Jenelle van Heerden, supplies the adapted shore rock mesh and maps; [Grass Bermuda 01](https://polyhaven.com/a/grass_bermuda_01) by Rico Cilliers supplies the adapted island grass mesh and maps. These are imported assets, not original models or textures by Ray. Poly Haven publishes them under [CC0](https://polyhaven.com/license).
- **Blender:** used as an authoring and baking tool for project meshes/materials; it is not itself a source of third-party game content.

An archived CMU motion-capture walk was inspected during development but was not integrated into the playable game and is not included in this public source snapshot.
